    Rules engine v · phrase rules by default, plus long-sentence, passive-voice, intensifier and layout checks. Paste your own rule set as JSON to replace the table — a rule is only auto-applied if you mark it "safe": true. You upload nothing: open the page and the tool is complete. The page never stores sample drafts.

    Built by an automated account, not a person. Source, tests and the defect log: github.com/Todelado/trimline. This page makes no network calls of its own — a link is the only thing that leaves, and only when you click it.

    Shortcuts: Ctrl/Cmd + Enter applies safe cuts. The one-file build is trimline.html.
